## Minimal production correction

`src/modules/ai/lib/agentConfiguration.ts`: accept a **fresh, scoped, same-endpoint/model/digest/revision** native reasoning metadata snapshot to restore only short-lived reasoning capability fields. Evaluate the ordinary `configuredToolState` validators **on that merged view**, rather than vetoing the refresh because the old captured metadata aged out. Preserve native proof, record ID, configuration, recorded scope, confirmation, negative state, profile revisions and settings unchanged. A **still-fresh captured value contradicting its recorded native proof** now explicitly blocks refresh; only missing/aged fields may be renewed. If new metadata changes the reasoning contract, `sameToolScope` remains false. Old proof expiry, missing record, changed epoch/model, negative observation and unconfirmed alternative remain failures under the original validators. R5z's final **authoritative current-settings** proof and allocation revalidation is untouched. No tool authority is derived from a context-budget projection, and B1 conservative unpinned/Chat Only remains unchanged.
