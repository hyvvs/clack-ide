## Source of the failure

R5t's first six 4096→65536 native calibration requests (`num_predict:32`, 0 tools) all succeeded. First production Automatic native-tool probe `inference-7` used `65536 / 512 / one tool`, received HTTP/IPC output and ended `length`. `src/modules/ai/lib/toolVerification.ts` properly escalated to `inference-8` at `65536 / 1024 / one tool`. R5s's `src-tauri/examples/r5k_acceptance.rs` had a second, unproven output whitelist: **32 allowed only without tools, 512 only with one tool, and 2048 Agent**. The exact production-authorized 1024 request was recorded by the acceptance interceptor and synchronously rejected **before** `handler(invoke)`; no R5t HTTP receive trace exists for inference-8. The saved `toolVerification` therefore reads `status:incomplete`, `outcome:transport`. This is a harness defect, **not** a demonstrated Nemotron or Clack production-runtime failure.
