## Source-level instruction audit — observable overlap, not a proven cause

The stable 9152-byte prompt concatenates **core invariants**, **default behavior** and **Coder persona** on every new normal inference. Specific repetitions (verified against the actual source, not stylistic opinions):

1. **Native tools only / no invented tools:** `CORE_SYSTEM_PROMPT` tool-contract inventory and denial rules; `DEFAULT_CLACK_BEHAVIOR` repeated “exposed” capability/command restrictions; Coder explicitly says use actual structured native functions, not pseudo-call markup. Actual tool schemas also describe individual permission/scoping constraints.
2. **Execute rather than narrate:** core tool-authority text; default `Execute, don't echo` and `Chain actions until done`; Coder's runnable software instructions reinforce acting, testing and repairing. The second is repetitive in intent, although Coder adds genuinely distinct quality requirements.
3. **Native shell rather than POSIX assumptions:** core historical `bash` warning; default shell workflow; Coder tool-use paragraph and server lifecycle paragraph; `bash_run` and background tool schema repeat shell/environment instructions.
4. **Foreground/background process safety:** core foreground-server prohibition; default managed-process instructions; Coder's long-running server paragraph; specific `bash_run`, `bash_background`, `bash_list`, `bash_logs` contracts. The repetition preserves an important enforced lifecycle boundary.
5. **Read/creation/edits:** core previously-read exact-string edit and new-file creation rule; default editing/path section; Coder read-before-edit paragraph; creation/edit native schemas. In an empty workspace, the instruction to inspect parent first adds legitimate safety, but does not require thousands of reasoning tokens.
6. **Approval and truthful completion:** core enforces approvals as structural authority; default explains the approval card; Coder says not to claim unobserved build/tests. These are related but carry distinct user-facing guarantees.

The Coder prompt contains **no instruction to produce a long private plan before first action**. Default behavior conditionally says to use an exposed planning capability before *long tool sequences*; it explicitly says execute immediately and be concise. No contradiction requiring 8192 reasoning tokens was found. No evidence shows the model was forced to reason rather than use `write_file`; first step used the tools successfully. There is redundant wording and a large optional-tool surface, but **no demonstrated causal connection** between either and the second reasoning-only generation.
